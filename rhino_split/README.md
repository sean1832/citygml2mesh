# 东京 GIS 数据集自动化处理与格式转换工具链

本工具链专为处理大规模东京 GIS 地形（DEM）与建筑（BLDG）网格数据设计。通过 **进程隔离**、**几何分块预重构** 和 **全自动批处理**，能稳定、高效地完成高精度的网格重构（QuadRemesh）、按 500x500 米网格切片、并最终导出为 3DM、OBJ 和 GLB 格式。

---

## 🛠️ 文件列表与功能角色

### 1. `RunAllZones.py` (多区块批处理启动器)
* **核心功能**：整体流程的调度器。自动扫描当前目录下的区块文件夹，提供交互式命令行界面。
* **特性**：
  * 支持输入特定序号列表进行连续导出（如 `1,2,3,5,8`）或输入范围（如 `1-3`）。
  * 采用 **分进程启动 Rhino** 的方式处理每个区块，区块处理完毕后自动关闭 Rhino。该机制能彻底释放 Rhino 占用的系统内存，从根本上防止因内存溢出（OOM）导致的程序崩溃。

### 2. `ProcessTokyoGIS.py` (Rhino 核心处理引擎)
* **核心功能**：运行于 Rhino 内部的实际数据处理器。负责数据导入、高度拟合、网格重构、瓦片物理切分与导出。
* **特性**：
  * **分批导入预重构**：按设定面数上限分批导入 GLB 地形，大幅降低单次重构时的 Rhino 负载。
  * **超大网格几何分割 (`split_mesh_by_face_count`)**：当单个大网格或批次面数超过 **150 万面** 时，脚本会自动采用包围盒（Bounding Box）长边中面切分算法，将其拆分为数个不超过 120 万面的子块进行独立重构，完成后再缝合。这彻底规避了 Rhino QuadRemesh 在面对特大网格时卡死的瓶颈。
  * **自适应面数调配**：可手动或根据原始面数自动调整 QuadRemesh 的缩减比例（默认 50%，若面数超 200w 则自动下调比例，以将最终面数控制在 100w 面左右，硬下线为 80w 面）。
  * **高精度瓦片切分**：采用 5x5 投射采样判定瓦片完整性，并自动物理切割落入瓦片范围内的建筑物单体。

### 3. `Export3dmToMesh.py` (3DM 网格格式导出器)
* **核心功能**：用于对最终生成的 3DM 文件进行二次格式转换。
* **特性**：
  * 自动扫描 `output/` 目录下的所有 `.3dm` 区块模型。
  * 静默打开 3dm 文件（自动忽略未保存修改提示），解除图层和物体的锁定/隐藏，选中全部网格，并在对应的区块文件夹下分别创建 `/obj` 和 `/glb` 子目录，导出整包的 OBJ 和 GLB 文件。

### 4. `CheckDEMFaces.py` (GLB 快速面数检测工具)
* **核心功能**：在不启动 Rhino 或完全加载 GLB 模型的情况下，通过读取 GLB 二进制报头快速解析出文件包含的顶点及三角面数。

## 🚀 使用指南

### 第一步：准备数据
将待处理的区块文件夹（如 `01-bunkyo-ku`、`05-nakano-ku` 等，文件夹内应包含 `dem` 或 `bldg` 子目录）放置在与脚本同级的目录下。

### 第二步：运行切片与重构流水线
1. 打开终端，切换到项目根目录 `J:\Projects\Sean\`。
2. 运行启动器：
   ```powershell
   python RunAllZones.py
   ```
3. 脚本会自动检测 Rhino 的路径，并列出扫描到的所有区块。
4. **选择处理区块**：
   * 输入 `0` 或直接回车：依次处理所有区块。
   * 输入特定区块序号（支持逗号分隔或范围）：例如输入 `1,2,3,5,8`，回车后将仅连续处理这 5 个区块。
5. 脚本将自动依次拉起 Rhino 完成格网采样、建筑切分、3DM 存储和瓦片导出。

### 第三步：一键导出整包 OBJ 与 GLB
当所有区块切片完成后，如果您需要获取各区块完整地形与建筑的最终合并模型：
1. 运行转换脚本：
   ```powershell
   python Export3dmToMesh.py
   ```
2. 脚本将自动依次后台打开 `output/` 下的各个 `.3dm` 文件，提取所有合并网格，并导出输出到：
   * `output/<区块名>/obj/<区块名>.obj`
   * `output/<区块名>/glb/<区块名>.glb`

## ⚙️ 核心配置说明 (位于 `ProcessTokyoGIS.py`)

如果您需要微调导出参数，可以直接修改 `ProcessTokyoGIS.py` 顶部的全局常量：

* `GRID_SPACING` (默认 `1.0`): 地形格网重建时的采样间距（米）。越小精度越高，但面数成倍增加。
* `TILE_SIZE` (默认 `500.0`): 切片瓦片的大小（米）。
* `ONLY_COMPLETE_FILES` (默认 `True`): 是否只保留完全铺满的地形瓦片（过滤边缘不完整瓦片）。
* `QUAD_REMESH_RATIO_OVERRIDES` (字典): 可针对 1-12 区块的特定区块单独分配 QuadRemesh 目标比例。例如：
  ```python
  QUAD_REMESH_RATIO_OVERRIDES = {
      "05-nakano-ku": 0.38, # 强制该区块只保留 38% 的面数
  }
  ```
* `JOIN_BUILDINGS_PER_TILE` (默认 `True`): 每个瓦片内的建筑网格是合并为一个整体对象还是保留独立单体。

## 💡 技术注意事项
1. **防卡死提示**：若某个区块中的 DEM 原始面数极大（如 Nakano-ku 的 270 万面），脚本启动的几何分割会自动将其切碎重构。请耐心等待其子块分别重构完成，最终第二阶段重构会自动消除接缝。
2. **Rhino 命令行模式**：工具链中的 Rhino 命令均采用 `_-` 前缀，这会让 Rhino 以命令行静默状态运行，不会弹出格式导出配置弹窗，确保批处理无人值守顺利运行。
